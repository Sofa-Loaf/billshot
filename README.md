# Billshot

Free, client-side GitHub Actions usage / billing explainer.

Drop or paste a usage report (or billing screenshot text). Billshot explains in plain English:

- Minute rounding (jobs under 1 minute still bill 1 minute — e.g. 12 seconds ≈ 1 minute)
- OS multipliers: Linux 1× · Windows 2× · macOS 10×
- What likely drove the bill

No account. No backend. No Stripe. Runs in the browser.

**Live:** https://28to3.me/apps/billshot.html (after same-cycle ship)
